## Organizer app setup

1. Install dependencies (run in project root):

```bash
npm install firebase
```

2. Add Firebase config to environment (for local development, create a `.env.local`):

```
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=...
NEXT_PUBLIC_FIREBASE_APP_ID=...
```

3. Start development server:

```bash
npm run dev
```

4. Open `/organizer` to sign in and manage tournaments.

Notes:
- The organizer pages use Firebase Auth (email/password) and Firestore. Enable them in your Firebase console.
- Team entry for matches is a simple prompt for now; you can expand the UI to add teams separately.
